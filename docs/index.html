1

Mod folder location

The compiled subsdk4 binary and its main.npdm file go in Yuzu's mod folder:

C:\Users\FlowUP\AppData\Roaming\yuzu\load\0100000000010000\Practice mod 1.0\exefs\
2

Turn it on in Yuzu

In Yuzu, right-click Super Mario Odyssey → Properties → check Practice mod 1.0 (or Practice mod BTT 1.3 if your game is on 1.3.0). Only check one of them.

3

Start the game and have fun

Once in the game, press L + D-Pad Left to open the BTT Studio menu!

1

Simple Mod Manager method (Recommended)

Just copy the Practice mod 1.0 folder from your downloads to the /mods/ folder of your SD card:

SD:/mods/Practice mod 1.0/contents/0100000000010000/exefs/subsdk4

Start Simple Mod Manager on your console and turn the mod on.

2

Atmosphere Direct method

Put the binary straight into the Atmosphere folder tree:

SD:/atmosphere/contents/0100000000010000/exefs/subsdk4

Controller Shortcuts & Quick Controls

Take full control of your practice sessions with simple, intuitive combinations.

Open / Close the menu L + D-Pad Left
Save position (Save State) D-Pad Left
Load position (Load State) D-Pad Right
Reload the scene (Kill Scene) D-Pad Up OR ZL + ZR
Previous scene (Prev Stage) D-Pad Down
Quick action wheel Hold R3 (Right Stick)
